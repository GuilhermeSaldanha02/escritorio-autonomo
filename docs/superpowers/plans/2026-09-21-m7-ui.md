# M7-UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o Office 2D fixture-driven com React, TypeScript e Phaser, pronto para revisão final sem integração com backend real.

**Architecture:** O fixture é a única origem concreta e é injetado no `OfficeDataProvider` através de `OfficeDataSource`. React lê somente o contrato; `OfficeCanvas` converte o snapshot em uma cena Phaser determinística baseada em layout e paleta versionados. Dados não confiáveis permanecem texto e a UI apenas apresenta governança e finanças, sem reproduzir regras de domínio.

**Tech Stack:** pnpm monorepo, React 19, TypeScript, Phaser, Vite, Vitest e Testing Library.

---

## Estrutura de arquivos

- `apps/office/src/fixtures.ts`: fixture estática, estados oficiais, governança e timeline demo.
- `apps/office/ui/src/data/*`: contrato, tipos, adaptador fixture e normalização segura.
- `apps/office/ui/src/office/*`: parser de layout/paleta, placement determinístico e descritores visuais.
- `apps/office/ui/src/components/*`: Dashboard, Inspector, Timeline e bridge React/Phaser.
- `apps/office/ui/src/styles/tokens.css`: única fonte de tokens visuais consumidos pela UI React.
- `assets/office/*.json` e `docs/M7-*.md`: contrato reconciliado e referências de direção visual.
- `apps/office/ui/src/**/__tests__/*.test.tsx`: testes comportamentais e de fronteira.
- `PROGRESS.md`, `QA.md` e `docs/M7-UI-HANDOFF.md`: acompanhamento, prova e handoff.
